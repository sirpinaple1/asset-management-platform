# M02 — 基础数据（公司/分类/位置/厂商/供应商/型号）

## 职责

维护资产主表的所有外键依赖表。纯 CRUD，无状态机，但 M03 以后所有模块的外键均指向这里，
必须在 M03 之前完成。

## 涉及的表

| 表 | 说明 |
|---|---|
| `company` | 公司主体，初始数据 SK |
| `asset_category` | 资产分类，`parent_id` 支持二级 |
| `asset_location` | 区域位置树，`parent_id` + `path`（materialized path） |
| `manufacturer` | 厂商（谁生产） |
| `supplier` | 供应商（从谁购买） |
| `depreciation_rule` | 折旧规则（结构只建，CRUD 实现低优先级） |
| `asset_model` | 型号，关联 category + manufacturer + depreciation_rule |

## 对外 API（每张表标准 CRUD）

```
GET    /api/v1/companies
GET    /api/v1/categories          # 返回树形结构
GET    /api/v1/locations           # 返回树形结构，支持 ?parentId= 查子节点
POST   /api/v1/locations
GET    /api/v1/manufacturers
POST   /api/v1/manufacturers
GET    /api/v1/suppliers
POST   /api/v1/suppliers
GET    /api/v1/models
POST   /api/v1/models
PUT    /api/v1/models/{id}
```

分类和位置需要返回树形结构（递归或前端自组装）。

## 依赖

- M01 必须完成（鉴权、Flyway V1 表结构已建）
- comm_public_basic：无直接依赖（基础数据不涉及用户权限校验以外的调用）

## 完成标准

```
mvn clean verify 通过
POST /api/v1/locations body={name:"示例科技物料仓", parentId:...} → 201
GET  /api/v1/locations → 返回层级树
GET  /api/v1/models?categoryId=1 → 返回该分类下的型号列表
```

## 初始种子数据

迁移脚本（`V20260819__seed_base_data.sql`）需插入：
- company: 示例科技有限公司，code=SK
- asset_category: 从现有 Excel 枚举（镀膜设备/辅助设备/检测设备/IT设备数码产品 等）
- asset_location: 从 Excel 路径解析（示例科技物料仓/IT部在用仓/IT仓库 等），构建层级树
