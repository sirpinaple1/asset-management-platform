# M05 — 调拨单（ATR）审批流

## 职责

资产跨部门/跨区域调拨的完整流程：调出申请→调入确认→资产归属更新。
对应现有系统 ATR 单，56 条历史数据。

## 涉及的表

| 表 | 操作 |
|---|---|
| `transfer_order` | 调拨单主表（ATR单） |
| `transfer_order_item` | 调拨明细（一单对多资产） |
| `asset` | 确认后更新 location_id / user_id / department |
| `asset_allocation` | 确认后关闭旧持有记录，新建调入方持有记录 |
| `asset_log` | 调拨操作写入日志，operation_type = 资产调拨 |

## 状态机

```
（调出方发起）→ PENDING
PENDING → COMPLETED   （调入方确认收到）
PENDING → CANCELLED   （发起方或管理员撤销）
PENDING → REJECTED    （调入方拒绝接收）
```

## 对外 API

```
POST   /api/v1/transfers                  # 发起调拨（指定资产列表 + 调入部门/区域）
GET    /api/v1/transfers                  # 列表，支持 status/date/dept 筛选
GET    /api/v1/transfers/{id}             # 详情（含明细行）
POST   /api/v1/transfers/{id}/confirm     # 调入方确认收到
POST   /api/v1/transfers/{id}/reject      # 调入方拒绝
POST   /api/v1/transfers/{id}/cancel      # 撤销（仅 PENDING 状态可撤）
```

## 业务约束

- 调拨单 `serial_no` 格式：`ATR` + `yyyyMMdd` + 4位序号，与 ARE/AOC 序号生成器复用同一工具类
- 确认时批量更新资产的 location_id / department / user_id（调入部门负责人），事务内完成
- `source` 字段区分手动调拨（MANUAL）与盘点触发调拨（INVENTORY_TRIGGERED，M08 调用时传入）
- 现有数据中调出/调入管理员格式为 "部门 工号 姓名+盘点"，迁移时剥离 "+盘点" 并匹配 user_id

## 完成标准

```
mvn clean verify 通过
POST /api/v1/transfers → 201，状态 PENDING
POST /api/v1/transfers/{id}/confirm → 相关资产 location 更新，asset_log 有记录
POST /api/v1/transfers/{id}/cancel  → 资产不变，单据状态 CANCELLED
```
