# M01 — 后端骨架与鉴权接入

## 职责

建立可运行的后端工程骨架，接通 comm_public_basic 鉴权，使后续所有模块有一个稳定的安全边界可依赖。

## 涉及的表

无业务表。Flyway V1 在本模块建好所有核心表结构（一次性建完）。

## 交付物

1. `asset-backend/` 单 Maven 模块，`pom.xml` 包含：
   - Spring Boot 3.x、MyBatis Plus 3.5.x、Flyway、Lombok、
     Spring Security、SpringDoc OpenAPI、Testcontainers
2. 包骨架：`config / common / auth / controller / service / mapper / entity / dto / enums`
   按限界上下文分包（asset/category/location/lifecycle/inventory/depreciation/consumption）
3. `AuthPort`：HTTP 调 comm_public_basic
   - `GET /login/checkToken` — token 有效性校验
   - `POST /login/userSystemAuth`（请求头 `systemCode: asset`）— 获取用户在 asset 的角色/权限
   - 本地缓存 30-60s TTL（Caffeine 或 Spring Cache），未命中回源
4. `TokenFilter`：从 `Authorization: Bearer <token>` 提取 token，调 AuthPort 校验，
   写入 `UserContext`（ThreadLocal，存 userId + username + roles）
5. `Flyway V1`：`V20260819__create_core_tables.sql`，建本项目所有核心表（见 ADR-0006）
6. `GET /api/v1/me`：受保护接口，返回当前用户信息，用于验证鉴权全链路

## 依赖

- comm_public_basic 已部署，接口契约须以 GitLab 原始版为准（见 STATUS.md 阻塞项）
- 无其他模块依赖

## 完成标准

```
mvn clean verify 通过
GET /api/v1/me 带有效 token → 200 + 用户信息
GET /api/v1/me 无 token → 401
GET /api/v1/me 过期 token → 401
```

## 单次 AI 会话切分建议

**会话 M01-A**（后端骨架）：建工程结构 + pom.xml + 包骨架 + 启动类 + Flyway V1 SQL
**会话 M01-B**（鉴权接入）：AuthPort + TokenFilter + UserContext + `/api/v1/me` + 单测

M01-A 必须先完成，M01-B 依赖它。
