# M06 — 实物信息变更单（AOC）

## 职责

记录资产实物信息（归属部门/使用人/区域/存放地点等）的变更过程，生成 AOC 单据，
支持查询变更历史和打印变更单。对应现有系统 AOC 单。

## 涉及的表

| 表 | 操作 |
|---|---|
| `change_order` | 变更单主表（AOC单） |
| `change_order_item` | 变更明细（一单可含多资产，记录变更前/后字段值） |
| `asset` | 变更确认后更新对应字段 |
| `asset_log` | 变更操作写入日志，operation_type = 实物信息变更 |

## 变更字段范围

仅限实物归属类字段，不含资产编码/分类/购入日期等固有属性：
`user_id / user_department / location_id / location_detail / company_id`

## 对外 API

```
POST   /api/v1/change-orders                  # 发起变更（指定资产列表 + 各字段新值）
GET    /api/v1/change-orders                  # 列表
GET    /api/v1/change-orders/{id}             # 详情（含变更前/后对比）
POST   /api/v1/change-orders/{id}/confirm     # 确认执行（真正更新 asset 字段）
POST   /api/v1/change-orders/{id}/cancel      # 撤销
```

## `change_order_item` 的变更前/后记录方式

```
change_order_item(
  id, order_id, asset_id,
  field_name   varchar(50),   -- 如 "user_id" / "location_id"
  field_label  varchar(50),   -- 如 "使用人" / "区域"（展示用）
  value_before varchar(500),
  value_after  varchar(500)
)
```

每台资产的每个变更字段一行，便于精确展示变更前后对比（对齐现有系统 AOC 打印格式）。

## 业务约束

- serial_no 格式：`AOC` + `yyyyMMdd` + 4位序号，复用同一序号生成器
- 确认时批量更新 asset 字段，同一事务内写 asset_log
- 现有系统 AOC 是打印格式导出（见 Excel File 5），新系统支持在线查看 + 打印预览

```
mvn clean verify 通过

```
