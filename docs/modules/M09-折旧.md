# M09 — 折旧（低优先级，Phase 4）

## 职责

按折旧规则计算资产账面净值，支持直线法折旧，生成月度折旧报表。
**本模块优先级最低，基础功能完成后再实现。**

## 涉及的表

| 表 | 操作 |
|---|---|
| `depreciation_rule` | 折旧方法 + 年限 + 残值率（M02 已建，Phase 4 才实现 CRUD 和计算）|
| `asset_depreciation` | 每月折旧计算结果明细（新建）|

```sql
asset_depreciation(
  id, asset_id, rule_id,
  period        varchar(7),   -- '2026-08'
  book_value    decimal(12,2), -- 期初账面净值
  depreciation  decimal(12,2), -- 本期折旧额
  net_value     decimal(12,2), -- 期末账面净值
  created_at    datetime
)
```

## 前提条件（实现前必须满足）

1. `asset.amount` 有真实购入价格（当前历史数据全为 0）
2. `asset_model.depreciation_id` 指向有效的折旧规则
3. 财务系统对接方案已确定（人工补录 or API 同步）

以上条件不满足时，本模块实现没有意义，维持 Phase 4 冻结。

## 折旧方法（初期只实现直线法）

```
月折旧额 = (原值 - 残值) / 使用月数
残值    = 原值 × 残值率
账面净值 = 原值 - 累计已折旧额
```

## 对外 API（Phase 4）

```
POST /api/v1/depreciations/run?period=2026-08   # 手动触发月度折旧计算
GET  /api/v1/depreciations/report?period=2026-08 # 月度折旧报表
GET  /api/v1/assets/{id}/depreciation-history   # 单资产折旧历史
```
