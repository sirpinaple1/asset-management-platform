# M07 — 盘点（Stocktake）

## 职责

发起盘点任务，扫码或人工核对资产实际位置与系统记录，处理盘盈/盘亏，
并在需要时触发调拨单（INVENTORY_TRIGGERED）。
对应现有系统中 ATR 单 "+盘点" 后缀体现的业务场景。

## 涉及的表

| 表 | 操作 |
|---|---|
| `stocktake` | 盘点任务主表 |
| `stocktake_item` | 盘点明细（每台待盘资产一行） |
| `asset` | 盘点确认后按差异结果更新 location/status |
| `asset_log` | 盘点处理写入日志，operation_type = 盘点处理 |
| `transfer_order` | 发现资产在错误位置时，从本模块创建 source=INVENTORY_TRIGGERED 的调拨单 |

## 状态机

```
盘点任务：PENDING → IN_PROGRESS → COMPLETED / CANCELLED
盘点明细：PENDING → MATCHED（实物与系统一致）
                   → LOCATION_MISMATCH（位置不符）
                   → NOT_FOUND（实物缺失，盘亏）
                   → EXTRA（系统无记录实物，盘盈）
```

## 对外 API

```
POST   /api/v1/stocktakes                         # 创建盘点任务（指定范围：区域/分类）
POST   /api/v1/stocktakes/{id}/start              # 开始盘点
GET    /api/v1/stocktakes/{id}/items              # 待盘资产列表
POST   /api/v1/stocktakes/{id}/items/{itemId}/scan # 扫码或人工确认（提交实际位置）
POST   /api/v1/stocktakes/{id}/complete           # 完成盘点，生成差异报告
GET    /api/v1/stocktakes/{id}/report             # 盘点报告（MATCHED/MISMATCH/NOT_FOUND/EXTRA 汇总）
POST   /api/v1/stocktakes/{id}/transfer           # 对 LOCATION_MISMATCH 批量创建调拨单
```

## 移动端扫码说明

扫码入口复用 new_app_mes uni-app 工程的扫码能力（参见 AGENTS.md），
`/scan` 接口接收 barcode 字符串，返回该资产在当前盘点任务中的 item 状态，
前端（或 PDA）展示确认/差异界面。
