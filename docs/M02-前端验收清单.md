## 已知测试环境限制

TRAE 浏览器自动化工具的请求捕获 hook 会拦截带 body 的 POST（XHR 与 fetch 均受影响），
导致自动化点击提交无法完成端到端验证；GET 不受影响。已通过以下方式交叉验证：

1. curl 直连 asset-backend(6006)：厂商/供应商 CRUD 全链路 200 ✅
2. curl 经 Vite 代理(5174)：POST 200 ✅（证明代理层正常）
3. 浏览器端 console 日志：`handleSubmit called → validate result: true → POST 发出`（network 面板可见请求）✅

**待用户在真实浏览器手动验收**：弹窗内填写表单 → 确定提交 → 弹窗关闭 + 列表刷新 + ElMessage 成功提示。
