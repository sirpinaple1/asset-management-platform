# 资产管理系统前端设计规范

## 1. 概述

本文档定义资产管理系统前端的视觉设计规范，作为后续所有前端页面开发的统一标准。设计目标：清晰、专业、易用的 B 端制造业管理界面。

## 2. 整体架构

### 2.1 布局结构

采用经典的左侧导航 + 顶部标题栏 + 内容区三栏布局：

```
┌─────────────────────────────────────┐
│  [Logo]     资产管理系统    [User] │ ← 顶部标题栏（60px）
├──────┬──────────────────────────────┤
│      │                              │
│ 全局 │         内容区               │
│ 导航 │                              │
│      │                              │
│ 64px │                              │
└──────┴──────────────────────────────┘
```

- **左侧全局导航**：64px 宽，深色背景 #1D2129，固定定位
- **顶部标题栏**：60px 高，白色背景，固定定位，含系统名称和用户信息
- **内容区**：左偏移 64px，顶偏移 60px，浅色背景 #F7F8FA

### 2.2 响应式策略

当前版本聚焦桌面端（≥1280px），移动端暂不支持。

## 3. 色彩系统

### 3.1 主色调

- **品牌蓝**：`#165DFF` - 主操作按钮、重要信息高亮
- **品牌青**：`#14C9C9` - 辅助模块（库存管理）

### 3.2 中性色

- **文字主色**：`#1D2129` - 标题、正文
- **文字次要色**：`#4E5969` - 辅助说明
- **文字禁用色**：`#86909C` - 禁用状态、图标默认色
- **边框色**：`#E5E6EB` - 卡片边框、分割线
- **背景色**：
  - 页面背景：`#F7F8FA`
  - 卡片背景：`#FFFFFF`
  - 导航背景：`#1D2129`
  - 导航激活背景：`#272E3B`

### 3.3 功能色

- **成功**：`#00B42A` - 成功状态、完成标识
- **警告**：`#FF7D00` - 警告提示
- **错误**：`#F53F3F` - 错误提示、危险操作
- **信息**：`#165DFF` - 信息提示

## 4. 图标系统

### 4.1 设计原则

- **线性风格**：统一使用描边（stroke）样式，避免填充式图标
- **笔画粗细**：
  - 导航图标：`stroke-width="1.5"`
  - 应用图标：`stroke-width="2.4"` ~ `2.6"`
- **圆角处理**：`stroke-linecap="round"` `stroke-linejoin="round"`

### 4.2 全局导航图标（20×20px）

| 模块 | 图标语义 | 颜色 |
|------|---------|------|
| 工作台 | 3柱仪表盘（2-8-5-12-10-7柱高） | #86909C（激活时背景 #272E3B） |
| 审批中心 | 勾选列表（2勾+1空） | #86909C |
| 资产管理 | 带标签盒子 | #86909C |
| 库存管理 | 3个堆叠箱子 | #86909C |
| 通知 | 铃铛（带红点） | #86909C |

**激活状态**：背景色改为 `#272E3B`，图标颜色保持 `#86909C`（不变白色）

## 9. 实施约束

### 9.1 禁止事项

- ❌ 不得使用填充式图标（solid icons）
- ❌ 不得自定义新的品牌色
- ❌ 不得偏离 8px 间距网格
- ❌ 不得修改全局导航宽度（固定 64px）

### 9.2 扩展规则

- 新增模块图标需与现有图标风格一致
- 新增功能色需先评审，避免色彩泛滥
- 组件变体需保持设计语言一致性

## 11. 交互能力规范

### 11.1 输入与触发

**鼠标交互**：
- 单击：主操作（打开详情、选中行）
- 双击：快速打开（表格行双击进详情）
- 右键：上下文菜单（表格行右键显示"复制/删除/导出"）
- 悬停：显示 Tooltip、按钮高亮、图标变色
- 鼠标样式：
  - 可点击元素：`cursor: pointer`
  - 禁用状态：`cursor: not-allowed`
  - 加载中：`cursor: wait`

**键盘交互**：
- `Tab`：焦点遍历所有可交互元素
- `Enter`：提交表单、确认弹窗
- `Esc`：关闭弹窗/抽屉、取消编辑
- `Space`：勾选复选框
- `Delete`：删除选中行（需二次确认）
- `Ctrl+S`：保存表单（需阻止浏览器默认行为）
- `Ctrl+F`：页内搜索（表格筛选框聚焦）
- 方向键：表格/列表内移动选中行

**拖拽交互**：
- 文件上传：拖拽文件到上传区域（带虚线框提示）
- 列宽调整：表格列头边缘拖拽调整宽度
- 看板排序：拖拽卡片改变顺序（预留，V1 暂无看板）

**滚轮交互**：
- 无限滚动：表格/列表滚动到底部自动加载下一页
- 回到顶部：超过 300px 显示右下角悬浮按钮

### 11.2 即时反馈

**加载态**：
- 按钮加载：文字改为"保存中..."，图标旋转，禁用点击
- 页面加载：骨架屏（Skeleton）显示内容结构轮廓
- 局部加载：表格数据加载时显示 spinner

**悬停提示（Tooltip）**：
- 字段说明：字段名旁的问号图标悬停显示含义
- 操作说明：图标按钮悬停显示操作文字（如复制、删除）
- 截断文字：表格单元格文字超长悬停显示完整内容

**表单校验**：
- 失焦校验：输入框失焦时校验格式（如手机号、邮箱）
- 实时校验：密码强度实时显示（弱/中/强）
- 提交校验：提交前整体校验，错误在字段下方显示红色文字
- 成功提示：绿色对勾 + "校验通过"

**操作反馈（Toast）**：
- 成功：绿色图标 + "保存成功"（2 秒自动消失）
- 失败：红色图标 + "保存失败：{原因}"（5 秒自动消失）
- 警告：橙色图标 + "库存不足"（5 秒自动消失）
- 可撤销：删除操作显示"已删除 — 撤销"（5 秒内可撤销）

### 11.3 表单与数据

**受控输入**：
- 所有表单组件使用 `v-model` 双向绑定
- 联动逻辑：选择公司自动过滤部门选项

**乐观更新**：
- 表格行内编辑：修改后立即更新 UI，请求失败回滚并提示
- 复选框切换：勾选立即生效，请求失败恢复原状态

**草稿自动保存**：
- 长表单每 30 秒自动保存到 `localStorage`
- 右上角显示"已保存"状态（带时间戳）
- 刷新页面提示"检测到未提交草稿，是否恢复？"

**防重复提交**：
- 提交按钮点击后立即禁用，显示加载状态
- 请求完成后恢复可用状态
- 使用请求 ID 防止重复提交

**粘贴批量录入**：
- 表格支持从 Excel 粘贴多行数据
- 粘贴时自动解析列对齐

### 11.4 导航与路由

**路由模式**：
- 使用 `history` 模式（无 `#` 号）
- 后端需配置 fallback 到 `index.html`

**浏览器导航**：
- 前进/后退按钮正常工作
- 返回时保持滚动位置
- 刷新页面保持当前页面状态（通过 URL 参数）

**面包屑导航**：
```
资产管理 > 资产列表 > 资产详情 [A001234]
```
- 每级可点击返回
- 当前页面高亮显示

**多页签工作台（预留）**：
- 用户可同时打开多个详情页
- 关闭页签前检查未保存内容
- 页签拖拽排序

**深链支持**：
- 详情页 URL 格式：`/assets/detail?id=123`
- 刷新页面保持当前详情
- 复制 URL 可分享给他人

### 11.5 实时与异步

**WebSocket 推送（预留）**：
- 审批状态变更实时推送
- 库存变动通知
- 连接断开自动重连

**轮询兜底**：
- WebSocket 不可用时降级为轮询
- 激活标签页 30 秒轮询一次
- 非激活标签页 5 分钟轮询一次（`visibilitychange` 监听）

**请求竞态处理**：
- 使用 `AbortController` 取消旧请求
- 快速切换筛选条件时只保留最新请求
- 防止后发请求结果覆盖先发请求

### 11.6 无障碍与安全

**键盘可达性**：
- 所有交互元素可通过 `Tab` 访问
- 焦点状态明显（蓝色描边）
- `Tab` 顺序符合视觉顺序（从左到右、从上到下）

**对比度**：
- 文字与背景对比度 ≥ 4.5:1（WCAG AA 标准）
- 禁用状态对比度 ≥ 3:1

**鉴权处理**：
- Token 过期前 5 分钟自动刷新
- Token 失效跳转登录页，保留当前路径（登录后返回）
- 敏感操作（删除、导出）需二次确认

**安全防护**：
- 用户输入展示前转义（防 XSS）
- 表单提交带 CSRF Token
- 敏感操作（删除、批量导出）弹窗二次确认

## 12. 验收标准

### 12.1 视觉还原度

- 图标风格与设计稿 100% 一致
- 颜色值误差 ±0（完全匹配 HEX 值）
- 间距误差 ±2px

### 12.2 交互完整性

- ✅ 所有按钮必须有 `hover` 状态
- ✅ 所有表单控件必须有 `focus` 状态（蓝色描边）
- ✅ 表格行必须有 `hover` 状态（背景变浅）
- ✅ 加载状态必须有视觉反馈（按钮禁用 + loading 图标）
- ✅ 表单校验必须行内显示错误
- ✅ 操作结果必须有 Toast 提示
- ✅ 删除操作必须二次确认

### 12.3 键盘操作

- ✅ `Tab` 可遍历所有可交互元素
- ✅ `Enter` 可提交表单
- ✅ `Esc` 可关闭弹窗
- ✅ `Ctrl+S` 可保存表单
- ✅ 焦点状态清晰可见

### 12.4 响应性能

- 首屏渲染 < 2s（本地开发环境）
- 模块切换动画流畅（60fps）
- 表格渲染 1000 条数据 < 500ms
